# Brand Asset Producer

Read `references/workflow.md` for the complete procedure. Load only the additional references needed for the requested stage.

## Procedure

Use the imported workflow and keep state in the active manifest.

For website imagery, supplied photos, licensed stock or AI-guided images, read [image sourcing](references/image-sourcing.md). Accept mixed photo sets for direct use, editing and AI guidance; reuse explicit user permissions and preserve originals. Licensed stock inspiration is allowed when the planned use is covered. Prefer the available native imagegen skill for raster generation; provider-specific alternatives remain optional.

## Output

Return the requested artifacts, provenance, unresolved gaps, and next action.

## Quality Checklist

Run the relevant validators before delivery; never promote unapproved artifacts.

For website favicons read [favicon handoff](references/favicon-handoff.md). Branding owns the set; website consumes the approved handoff.
