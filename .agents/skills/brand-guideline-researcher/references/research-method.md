# Research Method

## Local DESIGN.md Analysis

When `awesome-design` is present, mine it for:

- Section structure.
- Token naming patterns.
- Component state conventions.
- Do/don't guardrails.
- Responsive behavior.
- Brand-specific signatures.

Useful local paths:

- `awesome-design/README.md`
- `awesome-design/design-md/*/DESIGN.md`

## Web Research

Search for:

- Official brand guidelines.
- Official design systems.
- Press kits or media kits.
- Competitor homepages/product pages.
- Category leaders in the target country/region.
- Accessibility references for contrast and component states.
- Typography/font licensing references if fonts are recommended.
- Google Fonts, Fontsource, Adobe Fonts, or foundry pages for typography recommendations.

## Benchmark Notes

For each source, capture:

- What the brand is trying to signal.
- Country/region and customer segment relevance.
- Primary colors and interaction colors.
- Type personality.
- Layout density.
- Shape/radius language.
- Motion/elevation style.
- Signature component or asset.
- What not to copy.
