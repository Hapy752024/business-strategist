# Brand Guideline Researcher Workflow


Research before recommending.

Priorities:
- Inspect user-provided assets and local references first. For supplied website references, inspect actual desktop/mobile presentation where possible and record the specific visual principles to adapt/avoid; inaccessible pages remain unverified. Reuse the website's `design/reference-review.md` rather than repeating completed research. A narrow site-reference pass follows `../../brand-website-designer-builder/references/reference-sites.md`.
- Search official brand/design-system/press pages where possible.
- Compare 3-5 category leaders or competitors in the target country/region when available.
- Use `awesome-design/design-md/*/DESIGN.md` for local pattern examples.
- Separate evidence from interpretation.
- End with design implications and recommend the next decision the user should make.

Output:
- Source list.
- Repeated design patterns.
- Category conventions.
- Differentiation opportunities.
- Accessibility and consistency risks.

Use `references/research-method.md` for deeper benchmark structure.
