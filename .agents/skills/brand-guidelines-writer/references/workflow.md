# Brand Guidelines Writer Workflow


Assemble the final source of truth.

Do not finalize until `brand-quality-reviewer` has no unresolved HIGH findings.
Do not write final guidelines until all requested stages have explicit user approval.
Guide unresolved decisions: list what is missing, recommend what to approve or revise next, and ask for one decision at a time.

Include:
- Brand foundation.
- Research summary and sources.
- Logo system and usage.
- Color system.
- Typography.
- Imagery and iconography.
- Layout, radius, elevation.
- UI components and states.
- Motion system: pillars, element specs, and do's/don'ts — sourced verbatim from `motion/motion-guidelines.md`.
- Component library: install path, token wiring, and tier breakdown — sourced from `components/README.md`.
- Marketing assets.
- Do's and don'ts.
- Responsive behavior.
- File manifest.
- CSS branding file and agent-readable brand skill generated by `brand-exporter`.

Use `references/guideline-template.md` for the document outline.


## Quality Checklist

Run the skill's existing checks and do not claim completion with unresolved blockers.
