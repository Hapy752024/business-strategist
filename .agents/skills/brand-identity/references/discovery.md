# Discovery mode (route `brand-discovery-interviewer`)

Build the brand brief by interview, before any brand system, logo, palette, UI kit or marketing asset.

1. Ask exactly one question at a time; offer suggestions as `1.`, `2.`, `3.` so the user can answer with a number.
2. After each answer say what to answer next; if an answer is vague, ask one clarifying follow-up before continuing.
3. Question order:
   1. Main goal.
   2. Desired deliverables.
   3. Brand/company name or naming need.
   4. Industry and offer.
   5. Target customer segment and primary country/region.
   6. Primary decision-maker, buyer, user or stakeholder.
   7. Unique selling proposition or differentiation.
   8. Values/principles.
   9. Desired personality.
   10. Design preferences and constraints.
   11. Good examples and why they work. For website/image deliverables, reuse supplied URLs/photos or ask once for reference sites and any photo set for direct use or AI guidance; record none/delegated when applicable and apply `.agents/skills/brand-website-designer-builder/references/reference-sites.md` without repeating an answered intake.
   12. Required formats, tools and environments.
4. After the last answer, summarize the brief and ask for confirmation; the confirmed brief unlocks strategy.

Use the [question bank](question-bank.md) only when a better follow-up is needed.
