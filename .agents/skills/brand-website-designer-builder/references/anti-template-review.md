# Anti-template review

Flag generic defaults when they have no documented brand reason: interchangeable gradient blobs, universal bento grids, indiscriminate glass cards, one-radius-everywhere components, generic typography, arbitrary parallax, stock imagery unrelated to the segment, and identical centered hero layouts.

This is a review prompt, not a ban list. A familiar pattern may pass when it serves the selected concept, customer comprehension, accessibility, and performance. Record the reason and the memorable detail that makes the implementation specific.
