# Creative direction

Each territory must state:

- the audience and conversion job;
- one coherent aesthetic premise;
- display/body type roles and fallback fonts;
- dominant palette and semantic accents;
- spatial composition and responsive behavior;
- image/illustration/texture system;
- one high-impact motion moment and reduced-motion fallback;
- one memorable signature device;
- risks, accessibility impact, performance cost, and implementation notes.

Use the brand system as a constraint, not a template. Distinctiveness comes from a deliberate combination of type, composition, imagery, and interaction that makes the offer easier to understand.
