# Preference profile

For new sites and visual redesigns, first apply [reference-site and photo intake](reference-sites.md): ask once for admired sites and optional supplied photos if not already provided, declined or delegated. Inspect references before translating them into design choices. Do not restart this intake for design-preserving maintenance.

Ask only remaining high-impact questions, using concrete choices:

- restrained ↔ expressive; minimal ↔ layered; editorial ↔ product-led;
- geometric ↔ organic; warm ↔ cool; polished ↔ raw;
- static ↔ kinetic; familiar ↔ experimental; sparse ↔ dense;
- typography personality, imagery mode, motion appetite, locale/RTL, accessibility needs;
- three things the user likes and two patterns they dislike, with the quality/reason.

Store the answers with provenance. Do not infer taste from a single URL. An inferred preference remains reversible until confirmed or delegated.
