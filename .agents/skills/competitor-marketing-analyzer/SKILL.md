# Competitor Marketing Analyzer

## Success Criteria
- **Quantitative:** triggers on >=90% of competitor marketing queries; completes in <=15 tool calls; extracts from >=3 competitor URLs per run; zero fabricated pricing/positioning claims.
- **Qualitative:** positioning, CTAs, pricing signals, and proof points are separated; source URLs are cited for every claim; gaps in data are named.

## Workflow

1. Read `references/workflow.md` completely.
2. Use the canonical repository analyzer command documented in the workflow.
3. Prefer the active topic workspace and inspect provider failures.
4. Separate full-page evidence, HTTP fallback, and cached snippets.
5. Treat copy as positioning—not proof of demand or performance.

## Output

Produce sourced comparisons, category patterns, differentiation hypotheses, weak claims to avoid, and evidence gaps.
