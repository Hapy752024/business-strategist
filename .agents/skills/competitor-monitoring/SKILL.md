# Competitor Monitoring

## Success Criteria
- **Quantitative:** triggers on >=90% of monitoring/tracking queries; completes setup in <=12 tool calls; defines entities, fields, cadence, and alert thresholds; zero paid actors run without approval.
- **Qualitative:** like-for-like snapshots are diffed; mechanical noise is suppressed; observed changes are separated from strategic interpretation.

## Workflow

1. Read `references/workflow.md` completely.
2. Define entities, fields, cadence, baseline, and alert thresholds.
3. Obtain approval before paid traffic or local-location actors.
4. Diff like-for-like snapshots and suppress mechanical noise.
5. Separate observed changes from strategic interpretation.

## Output

Produce monitoring scope, source registry, schedule, snapshot paths, material changes, confidence, and recommended response.
