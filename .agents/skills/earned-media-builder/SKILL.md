# Earned Media Builder

## Workflow

1. Read repo-root `references/task-scope.md`; use the checked discovery, preparation or verification route and preserve the selected objective.
2. Read [workflow](references/workflow.md) for the selected mode. Read [qualification](references/qualification.md) for opportunity decisions.
3. Reuse approved audience/resource facts, existing search/extraction providers and Marketing workstream. Research missing public facts; ask only for unavailable private facts or actual decisions.
4. Discovery returns qualified/rejected candidates and gaps. Preparation produces exact materials and a version-2 execution plan. Verification inspects known source/target URLs with retained captures.
5. Read repo-root `references/marketing-execution.md` for publication, action ownership and completion; keep opportunity research separate from execution state.

## Output

Return only the selected packet or evidence-backed assessment. For multi-step work publish through `scripts/subprojects.py::publish_marketing_workstream`; never overwrite its state directly. Render owner steps with `scripts/marketing/execution.py`.

## Quality Checklist

Require audience fit, actual eligibility, reader benefit and dated source locators. Unknown fee/link attributes remain unknown. A reply, submitted form, catalogue label or provider snapshot cannot verify a placement. Do not buy ranking links, invent expertise or mass-post. Sending, account creation, publication and paid partnerships require applicable existing authorization; this skill implements preparation and observation only.
