# Idea Grill

Use this skill to turn solution language into a researchable customer/problem thesis.

## Workflow

1. Read `references/workflow.md` completely.
2. Ask one focused question at a time until minimum inputs are known.
3. Write or update topic-workspace intake artifacts.
4. Separate evidence, assumptions, counter-hypotheses, and unknowns.
5. Stop before collection when the segment or painful job is not researchable.

## Output

Produce a core hypothesis, assumptions, counter-hypotheses, customer-language search terms, riskiest assumption, and next evidence command.
