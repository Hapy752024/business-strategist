# Positioning mode (route `business-positioning`)

Select or revise the business position and its strategic trade-offs. Answer only the requested scope: a focused positioning question returns the decision and requested implications, not a launch plan.

## Stage checklist

1. Read repo-root `references/strategic-positioning.md` completely.
2. Compare specific customer-choice hypotheses before choosing the offer; reuse an existing selected position unless evidence or a material conflict warrants revisiting it.
3. Derive the consequential delivery choices the position needs, then separately assess benefit, imitation barrier and value capture using that shared method. Coherent operations alone prove no moat.
4. Use archetype and regional playbooks ([archetypes](archetypes.md), [regions](regions.md)) only when they change the decision.
5. Return infeasible or unvalued promises as a specific revision or test; never rationalize the founder's preferred answer.
6. Hand off only requested implications: delivery and management to operations mode ([operations](operations.md)), launch motion to GTM mode ([GTM](gtm.md)), marketing expression to `marketing`.

## Output

The selected position, rejected alternatives with reasons, evidence and decisive unknowns, requested implications and the next test.
