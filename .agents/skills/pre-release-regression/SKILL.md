# Pre-Release Regression

Read [release workflow](references/workflow.md). Discover the target application, comparison base, test commands and authorized environment. Use `webapp-testing` for browser execution when applicable.

Keep this skill focused on release scope and evidence; ordinary browser debugging belongs to `webapp-testing`. Report pass, fail, skipped and blocked separately. Local or preview checks do not establish production readiness or authorize deployment.
