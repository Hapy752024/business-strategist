# SaaS Fintech Pilot Designer

## Workflow

1. Read `references/workflow.md` and relevant regulatory reference completely.
2. Identify the learning goal, parties, data, risk, and conversion decision.
3. Choose the least risky test that can answer the question.
4. Use synthetic or minimized data before sensitive production data.
5. Define scope, non-goals, metrics, stop conditions, and paid conversion gate.

## Output

Produce test type, participant map, scope, data controls, timeline, metrics, evidence log, risks, and conversion decision.
