# Web Application Testing

Read [browser workflow](references/workflow.md). Discover the selected application's commands, URL and existing test framework; reuse its browser tests when available. Playwright and its browser binaries must be installed before execution.

For optional Python server orchestration, inspect [server helper](scripts/with_server.py) with `--help` first.

Use synthetic data, sanitize artifacts and stop before unauthorized live transactions or external messages. Report environment, observed behavior, evidence paths and untested coverage. For release-wide prioritization use `pre-release-regression`.
