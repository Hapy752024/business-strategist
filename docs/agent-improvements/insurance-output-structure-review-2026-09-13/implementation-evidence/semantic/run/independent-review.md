## Limits that affect interpretation

- The evidence is deliberately synthetic and explicitly labeled. This verifies treatment of known evidence categories; it does not validate the underlying markets, founder fit, pricing, demand, legal scope or recommendations through external research.
- [The initial task prompt](task-prompt.txt) disclosed both subsequent corrections in advance. [publish-followups.py](publish-followups.py) applies authored string replacements and records the follow-up responses. The saved outputs show correct semantic handling and real publication/history changes, but do **not** prove response to an unforeseen correction in a separate fresh conversation. The actor generated the correction workflow with knowledge of the intended assertions.
- Both cases begin with the same combined fixture copied across segment/journey/pain input files. This is a useful trap for evidence overclaiming, but not broad or independent source coverage. Original fixture wording remains preserved as source material; current narratives and source bindings explicitly point to the overriding interpretation correction.
- No case was selected, no prerequisite was passed, and no selected business plan or external handoff existed. Consequently this exercise does not test invalidation of an already executable plan, gate override behavior or downstream execution safety. Those require implementation tests or a separate controlled scenario.
- No numerical model was appropriate here. The observed restraint is a semantic pass; calculator correctness is outside this evaluation. The direct spelling comparisons and archive comparisons establish the saved results, not concurrency or crash-recovery behavior.
- This is a separate reviewer on the same configured host, not a blind cross-provider evaluation or repeated sampling. There is insufficient evidence to infer a pass rate or universal compliance. No new web retrieval, agents, provider calls, repository edits or publication operations were performed by the reviewer; only this report was written.

**Disposition:** accept these ten saved-artifact assertions as passed, with the behavioral and coverage limits above attached. No corrective rerun is required for an observed assertion failure because none was found. Do not describe this single fixture as broad production acceptance or as a fresh, unforeseen multi-turn evaluation.
