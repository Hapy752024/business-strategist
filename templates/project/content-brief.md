# Content brief {{brief_id}}

## brief_id
Unique ID such as CB-001.

## platform
Choose the intended publishing platform.

## format
Name the format and approximate length or dimensions.

## pillar
Name the content pillar this asset serves.

## audience_segment
Describe the evidence-backed target audience.

## hook
Write the first three seconds or first line.

## key_message
State the single message the audience should retain.

## proof
Use only evidence the owner can show.

## cta
State the requested next action.

## conversion_bridge
Name the exact page or step after the CTA.

## kpi
Give the KPI name, target and measurement window.

## owner
Name the accountable producer.

## evidence_refs
Link the evidence behind the audience and message.

## brand_voice_ref
Link voice.json or write null.

## status
Use planned, in_production, published, measured or dropped.
